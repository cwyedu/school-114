# 二林工商 AI 互動網頁製作講義

## 從學校網站整理資料，到用 AI 生成互動測驗網站

---

# 一、課程目標

透過這份講義，你可以學會：

1. 從學校網站整理科系資料
2. 設計適合國中生的題目
3. 將題目整理成 AI 容易理解的格式
4. 使用 JSON 建立題庫
5. 撰寫 AI Prompt
6. 讓 AI 自動生成互動網頁

---

# 二、資料來源

首先，我們先從二林工商官方網站取得各科資訊。

網站： [https://www.elvs.chc.edu.tw/ischool/publish_page/0/](https://www.elvs.chc.edu.tw/ischool/publish_page/0/)

透過網站可以整理出目前主要科別：

* 建築科
* 室內空間設計科
* 電機科
* 電子科
* 機械科
* 商業經營科
* 資料處理科

---

# 三、第一步：整理各科特色

在讓 AI 生成題目前，必須先知道每科「在學什麼」。

例如：

| 科別  | 學習內容          |
| --- | ------------- |
| 建築科 | 建築設計、工程製圖     |
| 室設科 | 室內設計、色彩搭配     |
| 電機科 | 電力控制、自動化      |
| 電子科 | 電路、晶片、智慧控制    |
| 機械科 | CNC、機械加工      |
| 商經科 | 行銷、電子商務       |
| 資處科 | 網站設計、多媒體、AI應用 |

這一步很重要。 因為 AI 必須先知道每科特色，才能產生適合的題目。

---

# 四、第二步：設計國中生看得懂的題目

## 原則

題目不要太像考試。

避免：

* 太專業
* 太艱深
* 太像教科書

應該：

* 有生活感
* 有畫面感
* 國中生看得懂
* 能快速理解科別特色

---

# 五、題目範例

## 建築科

Q：建築科的學生最有可能在學什麼？

A. 設計房屋藍圖 B. 烘焙蛋糕 C. 照顧動物 D. 製作服裝

✅ 答案：A

## 資料處理科

Q：資處科的學生最有可能在做什麼？

A. 製作網站與多媒體作品 B. 鋤頭與鏟子 C. 吉他與鋼琴 D. 烹飪鍋具

✅ 答案：A

注意： 「電腦與程式設計」容易讓國中生害怕。 因此改成：

* 製作網站
* 多媒體作品
* AI應用

會更有吸引力。

---

# 六、第三步：為什麼不能只用文字？

很多人會直接把題目貼給 AI：

「幫我做成網站」

但 AI 常常會：

* 排版混亂
* 題目漏掉
* 無法做互動
* 不容易修改

因此需要使用「結構化資料」。

最推薦的格式就是：

# JSON

---

# 七、JSON 是什麼？

JSON 是 AI 最容易理解的資料格式。

它可以清楚描述：

* 題目
* 選項
* 答案
* 科別
* 顏色
* 圖示

AI 就能自動生成互動網站。

---

# 八、完整 JSON 題庫範例

```json
[
  {
    "id": 1,
    "department": "建築科",
    "icon": "🏠",
    "question": "建築科的學生最有可能在學什麼？",
    "options": [
      "設計房屋藍圖",
      "烘焙蛋糕",
      "照顧動物",
      "製作服裝"
    ],
    "answer": 0,
    "description": "建築設計、工程製圖、房屋施工與測量。",
    "category": "工業類",
    "color": "#FFB74D"
  },
  {
    "id": 2,
    "department": "資料處理科",
    "icon": "💻",
    "question": "資處科的學生最有可能在做什麼？",
    "options": [
      "製作網站與多媒體作品",
      "鋤頭與鏟子",
      "吉他與鋼琴",
      "烹飪鍋具"
    ],
    "answer": 0,
    "description": "網站設計、多媒體製作、文書處理、AI應用與數位科技。",
    "category": "資訊類",
    "color": "#64B5F6"
  }
]
```

---

# 九、JSON 欄位說明

| 欄位          | 功能       |
| ----------- | -------- |
| id          | 題目編號     |
| department  | 科別名稱     |
| icon        | emoji 圖示 |
| question    | 題目       |
| options     | 選項       |
| answer      | 正確答案     |
| description | 科別介紹     |
| category    | 類別       |
| color       | 主題色      |

---

# 十、第四步：撰寫 AI Prompt

有了 JSON 後，接下來要寫 Prompt。

Prompt 就是：

「告訴 AI 要做什麼」

---

# 十一、AI Prompt 範例

```text
請根據以下 JSON 題庫，製作一個適合國中生的「二林工商科別探索互動網站」。

需求如下：

【網站風格】
- 活潑、有科技感
- 適合國中生
- 手機版優先（RWD）
- 卡片式設計
- 使用繁體中文
- 加入動畫效果

【功能需求】
1. 首頁顯示「二林工商科別探索」
2. 每次顯示一題選擇題
3. 點選答案後：
   - 顯示正確或錯誤
   - 顯示該科介紹
4. 有下一題按鈕
5. 題目全部完成後：
   - 顯示「你最有興趣的科別」
   - 顯示各科簡介
6. 顯示進度條
7. 每題搭配 emoji 圖示
8. 加入 hover 動畫與按鈕動畫
9. 答對時有慶祝效果
10. 背景要有職業探索感

【技術需求】
- 使用 HTML + CSS + JavaScript
- 不可使用後端
- 所有內容寫在單一 HTML 檔案
- CSS 要現代化
- JavaScript 要模組化
- 可直接開啟執行
```

---

# 十二、第五步：把 JSON 貼給 AI
